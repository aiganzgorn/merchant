# Правила репозитория `merchant`

Инструкция для агента (opencode). Относится только к этому репозиторию.

## Границы

- **Ядро чистое.** `src/gen.ts`, `src/world.ts`, `src/camera.ts` не знают ни про DOM, ни про
  canvas, ни про `window`. Любая логика мира запускается в Node.
- **Рендер только читает.** `src/render.ts` не меняет состояние мира.
- **Детерминизм.** В генерации и симуляции нет `Math.random()`, `Date.now()` и обращений к
  глобальному состоянию. Случайность — только через `world.rng` из `src/rng.ts`.
- **Ничего лишнего.** Новая зависимость — только если без неё никак. Фича, которую не просили,
  не добавляется.

## Порядок работы

1. Правки в `main`, без долгих веток.
2. `npm test` и `npm run build` зелёные — иначе работа не закончена.
3. Запись в `CHANGELOG.md`: что изменилось и зачем, одной строкой на пункт.
4. Коммит и пуш в `origin/main` сразу, не дожидаясь отдельной просьбы.

## Стиль

- Комментарии в коде — по-английски и только там, где код не объясняет сам себя.
- Текст интерфейса и документации — по-русски.
- Имена файлов и функций — по-английски, коротко.
